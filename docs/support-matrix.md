## 降级策略

| `ParseResult.status` | 含义 | 推荐 UI |
|----------------------|------|---------|
| `ok` | 矩阵内能力完整可用 | 正常渲染 |
| `partial` | 部分构造跳过或近似 | 渲染 + 警告条 |
| `unsupported` | 无法安全展示套表 | 纯文本或「请下载」 |
| `error` | 文件损坏 / 非 doc | 错误信息 |

渲染层**禁止**在 `unsupported` 时输出「看起来像成功」的错乱版式。  
分页/合并格在金标样张上仍为 FAIL/严重错位时，预览可显示警告，**不得**宣称与 WPS 一致。
